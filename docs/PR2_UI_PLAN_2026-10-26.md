# PR 2 主界面交互收口方案(2026-10-26)

> 前置:PR 0(afd2116..f110d1b)已落库。本轮目标=降低主界面交互复杂度,**不迁移预览控件**(PR 0 已确认 `self.preview` 挂载于右侧 `detail_stack` 第 0 页)、不新增功能、不动 AI 引擎/剪贴板监听/粘贴事务/图片工作区/加密存储/数据库。
> 改前截图:`docs/ui/2026-10-26-pr2/before_*.png`(默认 1040×680 / 窄 860×680 / 宽 1280×780 / 篮展开)。

## 1. 右侧详情区:显隐升级到 dock 级

**现状**:`preview_visible=False` 时仅 `detail_stack` 隐藏(af PR0),`right_dock`(#aiRightDock)整框留着——空页签头+标题占位,空间不放。`right_dock` 目前是局部变量,无名引用。

**方案**:
- `right_dock` 提为 `self.right_dock`;显隐单元从 `detail_stack` 改为 `right_dock` 整体——QHBoxLayout 自动忽略隐藏控件,左栏(历史列表)自然占满。
- 新增常驻展开/收起入口:品牌行右端 checkable 小钮(FIF.VIEW,tooltip「显示/隐藏右侧详情」),选中态=右栏可见,点击走 `toggle_preview`。
- `toggle_preview` 保持兼容层角色(测试三处在调):改操作 `right_dock`,写 `preview_visible` 配置并落盘,同步新钮选中态;`set_detail_mode`/页签选中态/切回预览页补刷新(PR0 修复)一律不动。
- 重启一致:init 读 `preview_visible` → `right_dock.setVisible` + 钮态;隐藏期间选中的内容,展开时由 `toggle_preview(True)` 内的 `update_preview()` 刷新。

**验收**:隐藏后左栏占满无空壳;「预览/处理」两模式与选中态不受显隐影响;隐藏→展开→切页签→重启,状态一致。

## 3. 导航收敛:左导航为唯一主导航

**对比**:

| | 品牌菜单(`_show_page_menu`) | FluentWindow 左导航 |
|---|---|---|
| 条目 | 剪贴板/工作流/私密区/设置 | 完全相同四项 |
| 常驻性 | 点击才弹出 | 常驻+当前页高亮 |
| 结构 | PR0 晨间补的 RoundMenu | `addSubInterface` 注册,stackedWidget 结构,module-split 等测试依赖 |

两者条目完全等价=双轨冗余。

**决策**:左导航为唯一主导航。品牌菜单删除(`_show_page_menu` 方法与其 connect);品牌行 `btn_settings` 与 `_open_settings` 一并删除(与左导航 BOTTOM「设置」完全重复);`btn_pinboard` 保留(图钉画布是独立窗口,无左导航入口,品牌行是它唯一的鼠标入口);`btn_brand` 保留品牌图标但转为非交互装饰(QLabel+图标,不再可点)。品牌行收敛为:品牌图标 + 标题 + … + [详情显隐] + [图钉画布]。

**调用方核查**:`_show_page_menu`/`_open_settings` 仅品牌行 connect 引用(PR0 新增,无测试依赖,grep 确认后删);`_open_pinboard` 保留;设置/工作流/私密区入口由左导航全程保留。
