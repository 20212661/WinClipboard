# 📋 WinClipboard — Windows 桌面剪贴板管理器

一个轻量、常驻系统托盘的 Windows 剪贴板增强工具,自动记录文本/图片/文件剪贴历史,
支持全局热键唤出、搜索、置顶、删除、自动粘贴与持久化。
界面为**单一 FluentWindow 主窗口**(PySide6-Fluent-Widgets 原生组件与主题,
左侧导航:剪贴板 / 工作流 / 私密区 / 设置,AI 服务并入设置页);剪贴板页为
**左右双栏**:左栏是卡片流 + 预览,右栏常驻 **AI 工作台 + 上下文篮**
(选中卡片即材料,解释/翻译/总结/润色一键直达,零散资料收进上下文包随取随用)。

![主界面](docs/ui/2026-10-25/main_history_light.png)

## ⚡ 快速 AI 入口(轮盘)

在设置页「AI 模型与服务」配置模型后,复制文字并按 **Ctrl + Alt + 空格**,在鼠标附近的轮盘选择解释、翻译、总结、润色、自定义提问或带资料提问。鼠标点击/拖动松开或数字 **1–6** 选择;中心、右键或 **Esc** 取消。

前四项可直接生成,后两项先输入问题。结果在浮窗显示,支持复制、明确点击粘贴回原窗口、存入历史和加入上下文包;**Ctrl + Enter** 发送,**Ctrl + Shift + C「复制 Prompt」**——不调用服务,把材料 + 上下文包 + 问题组装成完整 Prompt(经隐私确认)复制,粘给任意网页 AI 也行。生成期间不自动覆盖剪贴板,敏感内容发送前可遮盖或取消。设置页可以打开轮盘或更改热键;文本历史卡片右键也有"快速 AI…"。第 **6** 扇区「收入上下文包」不进 AI 窗口,直接把剪贴板内容收进当前上下文包。

第一版处理文本、一次显示完整回答;"停止"丢弃迟到结果,不撤回已发出的服务端请求。全局按住键拖动、截图识别、流式输出和连续对话尚未实现。当前旧 EXE 需要重新构建才包含此功能。设计与实现范围见 `docs/AI_QUICK_ENTRY_PLAN.md`。

## 🪟 右栏 AI 工作台 + 上下文篮(2026-10-15 起)

主界面剪贴板页改为**左右双栏**:左栏照旧是卡片流与底部预览,右栏(≥340px)从上到下是
**上下文篮**与**常驻 AI 工作台**——AI 能力不再藏在右键菜单里。

![快速 AI](docs/ui/2026-10-25/quick_ai_light.png)

**右栏 AI 工作台**怎么用:

1. 左栏点选任意**文本卡片** → 工作台"材料"行自动跟随(标题/摘要可见;生成中不抢占)。
2. 点 **解释 / 翻译 / 总结 / 润色** 直接发送(可再点击取消勾选,回到"提问"语义);
   或在提问框输入问题按 **Ctrl + Enter** 发送。
3. 没配 API Key?点 **复制 Prompt**(或模型下拉旁的「配置…」直达设置页):材料 + 勾选的上下文包 + 问题组装为完整
   Prompt,经 `privacy_scan` **自动脱敏**后复制——粘到任何 AI 工具都能用。
4. 回答出来后:复制 / **贴回原窗**(从外部窗口呼出主界面时的那个窗口)/
   存入历史 / 加入上下文包,四个按钮随意组合。
5. 点 **「工作流」** 下拉:列出已配置的工作流,以当前选中卡片为输入
   **弹出运行台并自动开跑**(遇到人工步骤/隐私门照常停下等人)。

**上下文篮**(context pack)怎么用:把希望 AI 知道的零散资料先收进来——

- 入口五路:卡片悬停/选中的 **「+入包」** 按钮、右键「加入上下文包」(多选段选可批量)、
  快捷浮层 **`Ctrl+B`**、快速 AI 轮盘第 6 扇区、内容查看器里选中一段文字右键加入。
- 篮内条目可**勾选启停**(暂停的不参与拼装)、上移下移排序、移除;每条约 tokens
  实时估算,预算进度条 >90% 警示、超预算如实标红(拼装时会截断低优先级条目)。
- 支持多包:头部下拉切换/新建;「预览」本地只读拼装结果,「复制」取走全文,
  「提问」把拼装结果 + 你的问题交给快速 AI 窗口。
- **`Alt + Enter`**(快捷浮层内)把当前上下文包拼装结果**直接贴回原窗口**。
- 与工作流联动:编辑工作流时上下文包选「当前活动包 (@active)」,提示词里写
  `{context}` 即自动注入;内置示例模板「结合上下文包:审阅代码 → 生成单元测试」
  开箱即演(「工作流」页 →「填入示例模板」)。
- 敏感条目入包需确认并单独标记;发送给 AI 前仍必经隐私闸。图片只存引用不发送。

## 🧩 工作流(步骤统一契约 · 六类步骤)

把剪贴板变成固定工作流的"控制台":**不强制接入任何 AI 接口**。每条工作流 = 一串步骤;步骤是满足统一契约的对象(运行前检查 / 执行 / 取消 / 序列化,`workflow_steps.py`),类型可自由组合:

| 步骤类型 | 干什么 |
|---|---|
| **本地 AI**(可选) | 直接调用 OpenAI 兼容接口,自动出结果;需在「AI 服务」配置 |
| **网页 AI** | 把 `{input}` 套进提示词模板 → **提示词自动复制到剪贴板**(可选自动打开网页,如 `https://chatgpt.com/?q={prompt}`);你去网页 AI 粘贴发送 |
| **人工确认** | 弹出等待面板:**📋 从剪贴板粘贴**(把网页 AI 的回答带回来)或直接编辑 → 确认后作为下一步输入 |
| **复制到剪贴板** | 把链上当前内容快照进剪贴板,链继续(不打断) |
| **文本变换** | 本地白名单操作:去首尾空白 / 转大小写 / 替换 / 正则替换 / 加前后缀 |
| **条件判断** | 正则闸:当前内容命中则继续;未命中则本步完成但**停止自动串联**(可手动继续) |

提示词占位符:`{input}` 与 `{previous}` 都等于上一步产出(首步 = 原始输入);`{origin}` 恒为工作流的原始输入;`{context}` = 工作流绑定的**上下文包拼装结果**(编辑页可绑定指定包或「当前活动包 (@active)」,未绑定时为空)。

本地 AI 步骤的**服务名留空 = 第一个已配置的服务**,模板不必写死名称;运行入口两处:剪贴板页右键条目 →「工作流」,或主界面右栏 AI 工作台的「工作流」按钮(以当前选中卡片为输入,自动开跑)。

**典型用法(A 的回答交给 B、B 的交给 C,全在网页端)**:

1. 左侧导航「工作流」页 → 「填入示例模板」(内置"网页 AI 串联"、
   "结合上下文包:审阅代码 → 生成单元测试"等示例,**无需任何密钥**;
   新建/编辑工作流也在该页)
2. 复制一段文字 → 剪贴板页右键条目 → 「工作流」→ 选一条运行
   (或右栏 AI 工作台 →「工作流」一键运行)
3. 运行台每步执行完停下:网页步骤提示词已在剪贴板 → 切到网页粘贴 → 复制回答 → 回运行台点「📋 从剪贴板粘贴」→「✓ 确认,继续」
4. 每一步的结果都可**编辑后再继续**(人在回路),随时可复制取走

配置存储在 `config.json` 的 `ai_workflows` 键(本地 AI 服务在 `ai_services`)。

> **密钥安全**:`ai_services[].api_key` 落盘时自动用 Windows DPAPI 加密(绑定当前
> 用户,与私密区同一机制),文件里不会留明文;旧版明文密钥在启动时自动升级,升级
> 过程也不会把明文残留在 `config.json.bak*` 备份里。想手工填密钥,直接在
> `config.json` 里写明文即可,程序下次启动会自动加密。
> **加密失败不降级**:DPAPI 保护失败时保存直接失败并保留原文件与备份——不会
> 静默改写为明文副本;新填的密钥在当前会话内可用,界面会明确提示"未保存"。

## 🛡 可靠性与失败语义(2026-10-06 起)

- **私密区失败保护**:文件不可读(解密失败/损坏)时原文件**保持原样不被覆写**,
  可用备份(bak1~3,损坏主文件与旧明文不进备份链)自动恢复并把损坏原件留档为
  `private.json.corrupt`;本会话的新增/删除只暂存内存并如实标注。放弃不可读
  原数据只能走「清空」/「清空全部数据」的显式破坏性流程(确认文案会说明)。
- **真实加密状态**:私密区页面按实际读取/保存结果显示「DPAPI 已加密 /
  旧明文未加密 / 无法读取 / 尚未保存」,不以"模块存在"推断。
- **复制/粘贴失败如实反馈**:剪贴板写入失败(如被其他程序占用)时不派发
  Ctrl+V、不提升历史、界面提示"剪贴板写入失败,请重试";快捷浮层在失败时
  不收起,可直接重试。工作流中的复制步骤失败会停链说明,不宣称"已复制"。
- **安装目录保护**:安装器拒绝向盘根/个人目录根/Windows/Program Files/项目
  目录等危险位置镜像;非空目标必须带有本应用安装标记才允许 `/MIR` 更新;
  卸载器删除前重新校验目录归属,标记无效即中止;只停止**本安装路径**的进程
  实例(先请求正常退出),不再强杀所有同名进程。
- **运行记录原子化**:`workflow_runs.json` 临时文件+原子替换,写入失败保留
  原文件;文件损坏时留档 `.corrupt` 后从空白重建,不隐式当作空历史覆写。

## 🚀 启动方式

桌面已有快捷方式 **剪贴板.lnk**,双击即可启动(无控制台窗口)。

也可以用文件夹里的:
- `启动剪贴板.vbs` —— 无窗口启动(推荐,等同快捷方式)
- `启动剪贴板.bat` —— 带控制台,报错时便于排查

两个启动器都会解析 Python 解释器(python.txt → hermes venv → PATH),然后启动
**唯一入口** `winclipboard_qt.py`(需 PySide6 + PySide6-Fluent-Widgets;缺失时启动器
会提示安装命令,不再有 tkinter 回退版)。

**Python 解释器解析顺序**(换环境/换机器时无需改启动器,无任何硬编码机器路径):
1. `python.txt`(与启动器同目录,内容一行:pythonw.exe 完整路径)——显式指定,优先级最高
2. 项目自带 `.venv\Scripts\pythonw.exe`(推荐,见「依赖」节)
3. PATH 上的 `pythonw.exe`

启动后:
1. 右下角系统托盘出现蓝色剪贴板图标 📋
2. 随便复制点东西(网页、文档、截图都行)
3. 按 `Ctrl + Shift + V` 显示主窗口,选条目回车即粘贴

## ⚙️ 配置(config.json)

```json
{
  "hotkey_mod": 6,        // 修饰键位掩码: Ctrl=2, Shift=4, Alt=1, Win=8(6 = Ctrl+Shift)
  "hotkey_key": 86,       // 主键虚拟键码: 86 = V
  "quick_mod": 1,         // 快捷粘贴浮层热键:修饰键(1 = Alt)
  "quick_key": 192,       // 快捷粘贴浮层主键: 192 = `(反引号, VK_OEM_3)
  "auto_paste": false,    // 选中条目回车后是否自动向当前窗口发送 Ctrl+V(默认关,只写剪贴板)
  "sensitive_guard": true,// 敏感内容自动识别并隔离(false 则关闭)
  "exclude_apps": [],     // 按应用排除:名单内程序的复制不入史(exe 名,设置页可视化维护)
  "cleanup_days": 0,      // 自动清理:删除 N 天前的未置顶条目(0 = 关闭)
  "disk_cap_mb": 0,       // 图片缓存上限 MB,超限从最旧删起(0 = 关闭)
  "encrypt_history": false, // history.json 用 DPAPI 加密(false = 明文,便于备份迁移)
  "max_items": 100,       // 最多保留多少条(置顶条目不计入)
  "theme": "auto",        // 界面主题: auto(跟随系统)/ light / dark,设置页切换即时生效
  "theme_color": "",      // 主题色(强调色)十六进制覆盖,如 "#0066CC";空串 = 库默认
  "mica": true,           // Mica 材质背景(Win11 生效;远程桌面等场景自动回退纯色)
  "ai_services": [],      // AI 服务: {"name","base_url","model","api_key"}(密钥自动加密)
```

缺失的键会自动用默认值补齐,所以手写的 `config.json` 只写要改的那几项也能用。

可用的一份。想换热键:**设置页 → 全局热键 → 「更改」直接按键录制**(立即生效,

## ❓ 常见问题

**Q: 按了 `Ctrl+Shift+V` 没反应?**
A: 该热键可能被其他软件占用(如某些浏览器)。到**设置页 → 全局热键 → 「更改」**
   直接按键录一个新组合(立即生效、冲突即时提示)。另外注意程序必须在运行
   (看托盘有没有图标)。

**Q: 怎么彻底退出?**
A: 右键托盘图标 → 退出。直接关闭主窗口只是隐藏,程序仍在后台。

**Q: Hermes 更新时提示「关闭其他进程以更新 Hermes」,在里面看到 pythonw.exe 是本程序?**
A: 说明本程序正跑在 Hermes 的 venv 上,常驻进程把 `hermes-agent\venv` 锁住了。
   先右键托盘退出本程序,再装上面「依赖」一节的 `.venv`,重启后就会用自带解释器,
   不再影响 Hermes 更新。临时救急也可以直接结束那个 pythonw.exe,再重开本程序。

**Q: 自动粘贴不生效?**
A: 自动粘贴默认是**关闭**的(更安全:选中条目只写剪贴板)。想要"选中即贴",
   设置页打开「自动粘贴」开关;若个别程序(游戏、远程桌面)仍不接收模拟按键,
   属于程序限制,关掉开关手动 `Ctrl+V` 即可。

**Q: 想清除所有历史?**
A: 右键托盘 → 清空历史(先确认,置顶条目保留,清空后 6 秒内可撤销)。
   或直接删除 `%APPDATA%\WinClipboard\history.json`。

**Q: 怎么编辑复制的图片?**
A: 双击图片条目打开**图片查看器**,点「✏ 编辑标注」**就在这个窗口里编辑**
   (不再另开编辑器窗口;右键 → 图片处理 / 画布右键 → 编辑标注 也都进这个
   查看器的编辑态)。外部工具优先:装了 **ShareX** 或 **ksnip** 会自动调起
   它们的编辑器(结果经剪贴板自动回流历史)。内置编辑参考 QQ 截图编辑:
   底部悬浮工具条,**矩形 / 圆形 / 箭头 / 画笔 / 文字 / 马赛克 / 裁剪**,
   可换颜色与粗细,拖动实时预览,工具保持激活便于连续标注;**标注全部是

   并回到查看态(结果自动进入历史;画布来的图同时原地更新画布),Esc 放弃
   编辑回到查看。

**Q: 置顶的图钉画布怎么收起 / 恢复?**
A: Esc 或右上角 ✕ 只是收起,钉住的图全部保留;再钉任意图片(`Ctrl+Shift+P`
   或右键 → 置顶到屏幕)即重新展开,程序重启时若上次画布处于打开状态也会
   自动恢复。画布状态存在 `pins\board.json`,图片副本存在 `pins\images\`
   (SHA256 去重),与剪贴板缓存完全隔离——从历史里删除原图不影响画布。

**Q: 图钉画布能只显示、不挡鼠标吗?**
A: 能,这就是「鼠标穿透」:`Ctrl+Alt+T` 或右键画布 → 鼠标穿透,开启后
   画布仍显示但点击/滚轮全部透给下面的程序(可对照写代码),再按一次
   `Ctrl+Alt+T` 退出。若退出热键被其他软件占用,程序会拒绝进入穿透,
   防止画布卡在穿透状态。

**Q: 复制了密码/银行卡号,为什么面板里找不到?**
A: 被自动识别为敏感内容,隔离到了私密区(不写入普通历史)。
   右键托盘 → 私密内容 查看、复制或删除;想关闭此功能把 `sensitive_guard` 改为 `false`。
   私密区文件使用 Windows DPAPI 加密(绑定当前用户账号),旧版明文文件启动时自动升级。

**Q: 复制文件(资源管理器里 Ctrl+C)能记录吗?**
A: 能。文件复制会以「📁 N 个文件」进历史,选中回车即可粘回资源管理器;
   如果文件已被删除,条目会在重启时自动清理。

**Q: 历史文件损坏了怎么办?**
A: 每次写入都会滚动备份最近 3 份(history.json.bak1~.bak3),
   主文件损坏时程序自动从最近的备份恢复;异常详情记录在 app.log。
   config.json 同样是原子写入 + 3 份备份,损坏时也会自动回退。

**Q: config.json 里的 API 密钥为什么是一串乱码?**
A: 那是 DPAPI 密文,不是损坏。密钥用当前 Windows 用户账号加密,复制到别的机器或
   换个用户都解不开(这时程序会把它置空并记一条日志,请重新填写)。
   想手工换密钥,直接把明文写进 `api_key`,程序下次启动会自动加密。
   注意:换用户后 `private.json`(私密区)同理不可读,这是有意为之的绑定。
   **DPAPI 的边界**:它保护的是静态磁盘数据(文件被拷走读不出);
   以当前用户身份运行的恶意程序可以调用同样的 API 解密,
   DPAPI 不是对此类威胁的防御。要跨机器迁移数据,请用
   「加密备份(可迁移)」——密码 + AES-256-GCM,与 DPAPI 无关。
