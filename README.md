# 📋 WinClipboard — Windows 桌面剪贴板管理器

一个轻量、常驻系统托盘的 Windows 剪贴板增强工具,自动记录文本和图片剪贴历史,
支持全局热键唤出、搜索、置顶、删除、自动粘贴与持久化。

## 🚀 启动方式

桌面已有快捷方式 **剪贴板.lnk**,双击即可启动(无控制台窗口)。

也可以用文件夹里的:
- `启动剪贴板.vbs` —— 无窗口启动(推荐,等同快捷方式)
- `启动剪贴板.bat` —— 带控制台,报错时便于排查

两个启动器都会**自动选择版本**:检测到 PySide6 时运行 Qt + Fluent 版(`winclipboard_qt.py`),
否则自动回退到 tkinter 版(`clipboard_manager.py`,只需 pywin32 + Pillow),保证始终能启动。

启动后:
1. 右下角系统托盘出现蓝色剪贴板图标 📋
2. 随便复制点东西(网页、文档、截图都行)
3. 按 `Ctrl + Shift + V` 弹出面板,选条目回车即粘贴

## ⚙️ 配置(config.json)

```json
{
  "hotkey_mod": 6,        // 修饰键位掩码: Ctrl=2, Shift=4, Alt=1, Win=8(6 = Ctrl+Shift)
  "hotkey_key": 86,       // 主键虚拟键码: 86 = V
  "auto_paste": true,     // 选中后是否自动模拟 Ctrl+V 粘贴
  "sensitive_guard": true,// 敏感内容自动识别并隔离(false 则关闭)
  "max_items": 100        // 最多保留多少条(置顶条目不计入)
}
```

想换热键(比如 `Alt+V`):把 `hotkey_mod` 改成 `1`,`hotkey_key` 改成 `86`,保存后重启程序。

## ❓ 常见问题

**Q: 按了 `Ctrl+Shift+V` 没反应?**
A: 该热键可能被其他软件占用(如某些浏览器)。编辑 `config.json` 换个组合,重启即可。
   另外注意程序必须在运行(看托盘有没有图标)。

**Q: 怎么彻底退出?**
A: 右键托盘图标 → 退出。直接叉掉面板只是隐藏,程序仍在后台。

**Q: 自动粘贴不生效?**
A: 少数程序(如部分游戏、远程桌面)不接受模拟按键。关闭 `auto_paste` 后,
   选中条目会只复制到剪贴板,你再自己 `Ctrl+V`。

**Q: 想清除所有历史?**
A: 右键托盘 → 清空历史(置顶条目会保留)。或直接删除 `%APPDATA%\WinClipboard\history.json`。

**Q: 怎么编辑复制的图片?**
A: 在面板里右键图片条目 → 图片处理。支持裁剪、左右旋转、按百分比缩放,
   以及方框 / 箭头 / 文字 / 马赛克标注(带撤销),完成后点「复制」直接放回剪贴板,
   或「压缩导出」转 JPG 调整质量、「保存」存成文件。

**Q: 复制了密码/银行卡号,为什么面板里找不到?**
A: 被自动识别为敏感内容,隔离到了私密区(不写入普通历史)。
   右键托盘 → 私密内容 查看、复制或删除;想关闭此功能把 `sensitive_guard` 改为 `false`。
   私密区文件使用 Windows DPAPI 加密(绑定当前用户账号),旧版明文文件启动时自动升级。

**Q: 复制文件(资源管理器里 Ctrl+C)能记录吗?**
A: 能。文件复制会以「📁 N 个文件」进历史,选中回车即可粘回资源管理器;
   如果文件已被删除,条目会在重启时自动清理。

**Q: 历史文件损坏了怎么办?**
A: 每次写入都会滚动备份最近 3 份(history.json.bak1~.bak3),
   主文件损坏时程序自动从最近的备份恢复;异常详情记录在 app.log。
